DevArc QR Invoice

Import vendor Swiss QR-bills from scanner text, PDF or photo

Swiss QR-bill (SIX Swiss Payment Standards) tools for Odoo 18 Community on top of the standard Swiss localization l10n_ch. For Swiss companies that receive QR-bills from vendors and send QR-bills to customers. The main feature is the import of vendor QR-bills; on top of that, the module adds checks and a clearer message to the QR-bill that l10n_ch prints on customer invoices.

Import of vendor QR-bills

  • Button Import QR-bill on the vendor bill list, menu Accounting > Vendors > Import QR-bill, or the button Read QR-bill on a draft vendor bill.
  • Input is the text of a QR code scanner, or a PDF or photo of the QR-bill. Only the QR code is decoded, there is no OCR. A PDF is searched on all pages, a document with more than one different QR-bill is rejected.
  • The vendor is found by IBAN, otherwise by name and ZIP, otherwise created. The bank account, currency, payment reference (QRR or SCOR) and one invoice line with the amount are filled and the document is attached. The bill stays in draft.
  • The bill reference and bill date come from the invoice number and document date of SWICO S1 billing information, when present. The unstructured message and billing information go to the notes.
  • Odoo fills its default expense account on the line and the tax stays empty, so you choose the account and VAT before posting.
  • A QR-bill payable to your own company is rejected.

Duplicate warning

Odoo 18 already shows its own duplicate banner on the bill. In addition, the import shows a warning with links when another vendor bill of the same vendor has the same payment reference with the same total, or the same invoice number. Some vendors reuse one QR reference on every invoice, so the reference alone is not enough. The new bill is created anyway.

QR-bill on customer invoices

The QR-bill itself is generated by the standard Swiss localization l10n_ch. This module changes the following:

  • With a QR-reference or Creditor Reference, the Unstructured Message of the QR code carries the invoice reference or number instead of a duplicate of the payment reference.
  • Two extra checks: CH or LI IBAN and amount between 0.01 and 999,999,999.99. A failing invoice is printed without the QR-bill page.
  • Warning on the customer invoice form that explains why the QR-bill cannot be generated.

Requirements

Odoo 18 Community with l10n_ch. Python packages: pip install zxing-cpp pypdfium2. License LGPL-3.
